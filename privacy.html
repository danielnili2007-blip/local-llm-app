Privacy policy

local-llm · last updated October 17, 2026

local-llm is a personal assistant that runs on its owner's own computer. This policy explains what it does with Google user data.

Data it accesses

Only the Google accounts its owner connects: Gmail messages (to search, read and draft emails), Google Calendar events (to read and add events) and Google Drive files (to find, read and create documents). It only accesses this data when the owner asks it to do something.

How the data is used and stored

  • Google data is used only to carry out the owner's requests, on the owner's own computer.
  • Sign-in tokens are stored only on that computer. Email and file contents are not copied to any server.
  • Google data is never sold, shared with third parties, used for advertising, or used to train AI models.

local-llm's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the app's data from the owner's computer removes everything it stored.
